アプリケーション（コードと入力の弱点）

メモリインジェクションMemory injection

メモリに悪意あるコードを潜り込ませる

代表例
  • 入力欄へのコード注入
  • eval() の悪用

タイムオブユースTime-of-use (TOU)

確認後〜使用時までに状態が変わる

代表例
  • ログアウト後のセッション
  • 競合状態

タイムオブチェックTime-of-check (TOC)

権限チェック後に割り込み改変する

代表例
  • ファイル差し替え
  • 二重送金

悪意のあるアップデートMalicious update

正規の更新を装い不正プログラムを入れる

代表例
  • 偽アプリの自動更新
  • マルウェア入り更新

SQLインジェクションSQL injection (SQLi)

不正なSQL文でDBを操作する

代表例
  • ' OR 1=1 --
  • 検索欄からの全件取得

クロスサイトスクリプティングCross-site scripting (XSS)

閲覧者のブラウザで悪意あるスクリプト実行

代表例
  • <script>の埋め込み
  • 掲示板への悪性投稿

OS・ハードウェア（基盤と機器の弱点）

OSベースの脆弱性Operating system (OS)-based

OS自体に存在する脆弱性

代表例
  • EternalBlue
  • 未適用の緊急パッチ

ファームウェアの脆弱性Firmware

ハード制御ソフトの脆弱性

代表例
  • Broadpwn
  • 改ざんされたFW更新

エンドオブライフEnd-of-life (EOL)

メーカーサポート終了で修正されない

代表例
  • Windows 7 の継続利用

レガシーハードウェアLegacy

古い機器で最新パッチを当てられない

代表例
  • XP搭載の古いATM
  • フロッピーディスク
  • VHSテープ

仮想化・クラウド（共有基盤の弱点）

VMエスケープVirtual machine (VM) escape

VM内からホストへ分離を突破する

代表例
  • ゲスト→ホスト侵入
  • ZombieLoad

リソースの再利用Resource reuse

再割当リソースの残存データが漏れる

代表例
  • 未消去メモリの再割当

クラウド固有の脆弱性Cloud-specific

マルチテナントなどクラウド特有の弱点

代表例
  • テナント間データ漏えい
  • 責任分担の曖昧さ

サプライチェーン（提供元に起因する弱点）

サービスプロバイダー起因の脆弱性Service provider

事業者側の管理不備が利用者に波及

代表例
  • 事業者の設定ミス
  • ハイパーバイザー欠陥
  • 事業者の内部不正

ハードウェアプロバイダー起因の脆弱性Hardware provider

CPU等の設計・実装に起因する

代表例
  • Spectre
  • Meltdown

ソフトウェアプロバイダー起因の脆弱性Software provider

サードパーティ製ソフトの弱点が波及

代表例
  • SolarWinds事件
  • 改ざんされた正規更新

暗号・設定（運用上の弱点）

暗号化の脆弱性Cryptographic

弱い暗号や鍵管理不備による弱点

代表例
  • SSL 2.0 の使用
  • 鍵の不用意な公開

誤った設定による脆弱性Misconfiguration

設定ミスや初期設定のままの弱点

代表例
  • ストレージ誤公開
  • 初期設定のまま
