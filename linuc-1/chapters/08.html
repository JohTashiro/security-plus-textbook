08 ストレージとファイルシステム

パッケージで入れたソフトも、ログも、ホームもディスク上にあります。この章ではデバイスの見分け、パーティション、ファイルシステム作成、マウント、LVM、容量確認を実務単位で押さえます。

1. ストレージの種類とデバイスの見え方

種類 特徴のイメージ
HDD 磁気ディスク。安価・大容量寄り
SSD フラッシュ。高速・耐衝撃寄り
光学 光学メディア（現場では稀）

カーネルからは /dev/sda、/dev/nvme0n1、/dev/vda（仮想）などとして見えます。

lsblk
lsblk -f
sudo fdisk -l
cat /proc/partitions

Version 11.0 では lsblk / blkid / df / du が明示的です（「11.0で特に重視」）。

2. パーティション（MBR / GPT）

形式 感覚
MBR 古め。プライマリ数などに制約
GPT 現行主流。UEFI と相性が良い

UEFI 起動では ESP（EFI System Partition） が必要になることが多いです。

sudo fdisk /dev/sdb          # 対話でパーティション
sudo gdisk /dev/sdb          # GPT 向け
sudo parted /dev/sdb print

用途に応じた割り当ての定番:

マウント 置きたいもの
/ システム本体
/boot カーネル・ブート関連
/home ユーザデータ
/var ログ・可変データ
swap メモリ不足時の退避

3. ファイルシステムの作成とスワップ

代表例:

FS メモ
ext4 汎用で多い
XFS 大容量・並列寄り（RHEL 系の root でも多い）
VFAT / exFAT 互換・リムーバブル（exFAT は 11.0 で明示）
Btrfs スナップショット等の先進機能
tmpfs メモリ上 
sudo mkfs.ext4 /dev/sdb1
sudo mkfs.xfs /dev/sdb1
sudo mkswap /dev/sdb2
sudo swapon /dev/sdb2
sudo swapoff /dev/sdb2

スワップファイル（11.0 で fallocate 等が列挙）:

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

4. マウントと /etc/fstab

sudo mkdir -p /mnt/data
sudo mount /dev/sdb1 /mnt/data
mount | grep data
sudo umount /mnt/data

永続化は /etc/fstab。デバイス名より UUID やラベルが安全です。

sudo blkid /dev/sdb1

UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx  /mnt/data  ext4  defaults  0  2

リムーバブルは /media 配下に自動マウントされる環境が多いです。一般ユーザがマウントできるようポリシーを組む話も出題・現場の両方に出ます。

破損疑いのときはアンマウントしてから fsck（ext 系）など。XFS は xfs_repair 寄りです。本番はバックアップと保守窓を先に。

5. LVM 概要

層 意味
PV（Physical Volume） ディスク／パーティションを LVM 化
VG（Volume Group） PV を束ねたプール
LV（Logical Volume） VG から切り出した論理ディスク

利点: 容量の動的拡張がしやすい。欠点: 層が増え、バックアップ／障害切り分けの手順が一段増える。

sudo pvcreate /dev/sdb1
sudo vgcreate vgdata /dev/sdb1
sudo lvcreate -n lvapp -L 20G vgdata
sudo mkfs.ext4 /dev/vgdata/lvapp

Version 10.0 はスナップショットにも触れる一方、11.0 草案の列挙は動的拡張・縮小中心です。概念として「薄いコピーを取れる」程度は押さえておくと現場で助かります。

6. 容量と i ノード

df -h
df -i
du -sh /var/log
du -h --max-depth=1 /var | sort -h

「ディスクは空なのに書き込めない」→ i ノード枯渇（df -i）が定番です。

7. 現場チェック

  • [ ] lsblk / blkid でデバイスと UUID を辿れる
  • [ ] GPT と ESP の関係を説明できる
  • [ ] mkfs と mkswap / swapon ができる
  • [ ] /etc/fstab に UUID で追記し、再起動後もマウントされる
  • [ ] PV / VG / LV の関係を図で説明できる
  • [ ] df と du の違いを言える

手元 VM に追加ディスクを1本付け、パーティション → mkfs → fstab → 再起動確認まで一度通してください。
