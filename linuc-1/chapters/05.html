05 テキスト処理

ログや設定の調査は、ほとんどがテキスト処理です。パイプでつなぐ前提（第03章）の上に、フィルタ・正規表現・簡易編集を載せます。

1. 見る・数える・切り出す

cat file.txt
less file.txt          # 長いファイルは less
head -n 20 file.txt
tail -n 20 file.txt
tail -f /var/log/syslog   # 追従（ディストリでパス差あり）
wc -l file.txt

列の切り出し:

cut -d: -f1,3 /etc/passwd

並べ替えと重複:

sort file.txt
sort -n numbers.txt
uniq              # 連続する重複行をまとめる（事前に sort が多い）
sort file.txt | uniq -c | sort -nr

変換:

tr 'a-z' 'A-Z' < file.txt

Version 10.0 では textutils 系が多く列挙されます。Version 11.0 では実務頻度の高いものへ寄せつつ、hexdump などが見えます（「11.0で特に重視」は現行主流コマンドの習熟）。全部を暗記するより、よく使う組み合わせを手で打つのが先です。

2. grep と正規表現

grep 'error' /var/log/syslog
grep -i 'error' file.txt          # 大文字小文字無視
grep -R 'Listen' /etc/ssh/
grep -n 'pattern' file.txt        # 行番号
grep -v '^#' file.txt             # 一致しない行
grep -E 'error|warn' file.txt     # 拡張正規表現
grep -F 'a+b' file.txt            # 固定文字列（メタ文字を解釈しない）
記法 意味の例
. 任意の1文字
* 直前の繰り返し
^ $ 行頭・行末
[] 文字クラス
\| 選択（拡張では grep -E） 
grep -E '^[0-9]+$' ids.txt
grep -E 'failed|refused' /var/log/auth.log

egrep / fgrep は歴史的別名です。現行では grep -E / grep -F を主に覚えます。

3. sed による置換・削除

sed 's/foo/bar/' file.txt           # 各行最初の foo
sed 's/foo/bar/g' file.txt          # 行内すべて
sed -i 's/foo/bar/g' file.txt       # ファイルを直接変更（事前バックアップ推奨）
sed -n '10,20p' file.txt            # 10〜20行を表示
sed '/^#/d' file.txt                # コメント行削除の例

パイプ例:

grep 'sshd' /var/log/auth.log | sed -E 's/.*sshd\[[0-9]+\]: //'

本番設定を sed -i する前に、出力だけ確認する癖を付けます。

4. awk の入り口

列処理の定番です。LinuC の列挙は sed/grep 中心でも、現場では awk が頻出なので最低限を押さえます。

awk -F: '{print $1}' /etc/passwd
ps aux | awk 'NR>1 {print $2, $11}'
awk '/error/ {print $0}' app.log

「区切り文字を決めて列を出す」ができれば、多くの調査が速くなります。

5. vi の最低限

標準で使える編集として vi / vim が範囲に入ります。

操作 キー
挿入開始 i / a
コマンドモードへ Esc
保存終了 :wq
破棄終了 :q!
検索 /pattern 次は n
行削除 dd
取り消し u

モードを意識する（挿入とコマンド）ことが最初の関門です。大きな編集は慣れで、試験・現場とも「開いて直して保存」ができれば十分です。

6. 実務パターン

# エラー行だけ抜く
grep -i error app.log | tail -n 50

# アクセス多い IP を集計（ログ形式依存）
awk '{print $1}' access.log | sort | uniq -c | sort -nr | head

# 設定の有効行だけ
grep -vE '^\s*#|^\s*$' /etc/ssh/sshd_config

7. 現場チェック

  • [ ] head / tail / less / wc を使い分けられる
  • [ ] grep -E と簡単な正規表現でログを絞れる
  • [ ] sed で置換し、変更前に画面確認できる
  • [ ] sort | uniq -c で集計できる
  • [ ] vi で開く・直す・保存できる

手元の Linux で /var/log やサンプルテキストを使い、同じ操作を3回繰り返してください。
