配置とゾーン

デバイスの場所Device placement

重要機器を物理的に安全な場所へ置く

代表例
  • 中間階のサーバルーム
  • 入退室管理

セキュリティゾーンSecurity zones

信頼度に応じてネットワークを分割する

代表例
  • DMZ
  • 内部／機密ネットワーク

アタックサーフェスAttack surface

攻撃の入り口・接点の総体

代表例
  • ログインフォーム
  • 不要ポートの開放

接続性Connectivity

接続を維持する可用性の考え方

代表例
  • サーバー冗長化
  • 代替ネットワーク経路

フェイルセーフ

フェイルオープンFail open

故障時もアクセス継続（可用性優先）

代表例
  • 障害時にドア開放
  • 業務継続を優先

フェイルクローズFail closed

故障時は閉じる／止める（安全優先）

代表例
  • ゲート自動ロック
  • 機密システムの停止

中間装置

ジャンプサーバーJump server

管理アクセスの中継点

代表例
  • 本番サーバーへの踏み台
  • 操作ログの一元化

プロキシサーバーProxy server

クライアントの代理として中継する

代表例
  • Webキャッシュ
  • URLフィルタ

IPSとIDSIPS/IDS

不審通信を検知／防止する

代表例
  • シグネチャ照合
  • 異常トラフィック検知

ロードバランサーLoad balancer

複数サーバーへ負荷を分散する

代表例
  • ラウンドロビン
  • Webサーバー振り分け

センサーSensors

異常や障害の兆候を監視する

代表例
  • サーバルーム温度
  • ネットワーク監視センサー

境界・アプリ防御

EAPExtensible Authentication Protocol (EAP)

拡張性の高い認証フレームワーク

代表例
  • EAP-TLS
  • 無線LANの相互認証

WAFWeb application firewall (WAF)

Webアプリ向けの攻撃を防ぐFW

代表例
  • SQLインジェクション遮断
  • XSS対策

次世代ファイアウォールNext-generation firewall (NGFW)

アプリ認識など多機能を統合したFW

代表例
  • SNS利用制限
  • URLフィルタ＋IPS

ファイアウォール（Layer 4／7）Firewall (Layer 4/7)

OSIの層ごとに制御粒度が違うFW

代表例
  • L4: IP・ポート制御
  • L7: HTTP内容制御

セキュア接続

VPNVirtual private network (VPN)

公衆網上に暗号化トンネルを張る

代表例
  • 在宅からの社内接続
  • 出張先の安全アクセス

TLSTransport Layer Security (TLS)

通信の暗号化・完全性・認証

代表例
  • HTTPS
  • カード情報の保護

SD-WANSoftware-defined wide area network (SD-WAN)

WANをソフトで最適制御する

代表例
  • 店舗ごとの最適回線
  • アプリ別経路選択

SASESecure access service edge (SASE)

接続とセキュリティをクラウド統合

代表例
  • FW＋VPN＋ZTNAの統合
  • エッジでの一元防御
